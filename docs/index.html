Claude Code v2.1.309: sandbox and permission-check hardening

Claude Code v2.1.309 fixed sandboxed Bash running shell startup files outside the sandbox, sandboxed commands being able to modify the --mcp-config file, macOS denyWrite globs being bypassed through symlinks, and several Bash permission-check gaps including an Edit deny rule that did not block Bash redirects. Nearby releases added a sandbox.allowNestedUserNamespaces option (which can bypass some file protections) and a claude_code.safety_event OpenTelemetry event.

💡 Why it matters: Teams that rely on Claude Code's sandbox and deny rules should upgrade, and the new telemetry event makes policy enforcement easier to audit.
