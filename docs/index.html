Claude Code v2.1.299–v2.1.302: idle compaction, auto-mode model override, richer telemetry

Claude Code now compacts a 200K+ token conversation left idle for about 54 minutes before its one-hour prompt cache expires, with a /config toggle and a token-minimum override. The same releases add a CLAUDE_CODE_AUTO_MODE_MODEL setting, OpenTelemetry events that split cache writes by lifetime, and a retry watchdog cap for usage limits.

💡 Why it matters: Idle compaction avoids reprocessing a huge context after a break, which directly cuts cost and latency for long-running sessions.
