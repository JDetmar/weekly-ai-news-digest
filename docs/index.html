Claude Code v2.1.309 hardens sandbox and permission checks

Claude Code v2.1.309 fixed sandboxed Bash commands running the shell's startup files outside the sandbox, macOS denyWrite globs missing symlinked paths, and sandboxed commands being able to modify the --mcp-config file. It also closed Bash permission-check gaps around redirects and compound commands that change directory; the earlier v2.1.305 added sandbox.allowNestedUserNamespaces, which lets sandboxed commands get around the sandbox's file protections.

💡 Why it matters: Anyone running Claude Code with sandboxing or auto-accepted edits should update, since these fixes close paths that let commands escape their intended limits.
