Claude Code hardens sandbox and permission checks (v2.1.305–v2.1.309)

Release 2.1.309 fixes sandboxed Bash commands running shell startup files outside the sandbox, macOS denyWrite globs not applying through symlinks, and sandboxed commands being able to modify the MCP config passed with --mcp-config. It also closes several Bash permission-check gaps; 2.1.305 added sandbox.allowNestedUserNamespaces, which lets sandboxed Linux commands get around the sandbox's file protections.

💡 Why it matters: If you rely on Claude Code's sandbox or deny rules to contain an agent, these fixes are worth picking up now, and the new nested-namespace option should be enabled deliberately.
