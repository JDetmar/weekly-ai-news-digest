Git security vulnerabilities announced

The Git project released Git 2.56.1, with backports to 2.55.1 down to 2.50.2, fixing six vulnerabilities. They include arbitrary code execution when recursively cloning a malicious repository, path traversal via a server-advertised HEAD, and memory corruption in merges and binary patches.

💡 Why it matters: Developers, CI runners and any application that bundles Git should update now, especially anything that clones untrusted repositories, as agents increasingly do.
