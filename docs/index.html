Git security vulnerabilities announced

The Git project released Git 2.56.1, with backports to maintenance series back to 2.50.2, fixing six vulnerabilities. They include arbitrary code execution when recursively cloning a malicious repository, writes to unintended files, and memory corruption when processing merges or binary patches.

Why it matters: Everyone who clones untrusted repositories, including autonomous coding agents, should update Git and any applications that bundle it.
