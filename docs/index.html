MCP for agent-to-agent comms may be the riskiest protocol you've never heard of

Google and four other organizations have acknowledged, over five months, vulnerabilities where one compromised agent spreads malicious instructions to other internal agents. The attacks exploit trust gaps in MCP, where agents explicitly trust each other and MCP servers store credentials for each agent.

💡 Why it matters: Teams wiring agents together need to treat inter-agent messages as untrusted input and add guardrails at every hop.
