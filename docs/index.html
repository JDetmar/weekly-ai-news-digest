External sandboxes for coding agents

Simon Willison describes an external sandbox pattern in which the agent stays outside and only the code it executes runs in a dedicated sandbox. 💡 Why it matters: The pattern works with Claude Code, Codex, and Pi, so it is a practical way to limit prompt-injection damage today.
