Claude Haiku 5.5

Claude Code v2.1.299-v2.1.302: idle compaction, richer OpenTelemetry, auto-mode model override

Claude Code now compacts a 200K+ token conversation left idle for about 54 minutes so the next message does not reprocess it after the one-hour prompt cache expires. 💡 Why it matters: Idle compaction cuts the cost and latency of resuming long sessions, and the telemetry additions make agent behavior easier to audit.
