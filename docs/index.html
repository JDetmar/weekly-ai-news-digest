Anthropic's Claude VS Code extension backdoored on Cursor for nearly 12 hours

Malicious version 2.1.313 of Anthropic's official Claude extension was published through Anthropic's account on Cursor's marketplace and reached at most 5,000 users before version 2.1.314 replaced it hours later. Researchers say the payload went looking for cloud credentials, and neither Cursor nor Anthropic had explained how the account was compromised.

💡 Why it matters: Extensions auto-update by default in Cursor, so anyone who had this extension installed should check whether they received 2.1.313 and treat cloud credentials on that machine as potentially exposed.

Claude Code v2.1.314-v2.1.319: stricter permission guardrails and auto-mode changes

Recent releases add permissions.blockWritesOutsideWorkingDirectories (Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode) and permissions.denyInsteadOfPrompting (a call that would wait on a prompt is denied and the turn continues). v2.1.319 also backgrounds MCP tasks in the terminal and changes auto mode behind LLM gateways so calls the server cannot check are asked about or denied.

💡 Why it matters: Teams running unattended or gateway-fronted sessions get firmer guardrails, but gateway users should review auto-mode behavior (CLAUDE_CODE_AUTO_MODE_SERVER=0 keeps the old classifier fallback).
