pull_request_target blocked by default December 2

Starting December 2, 2026, GitHub Actions will block pull_request_target events by default in all public repositories unless an Actions event policy explicitly allows them; enforcement had been planned for November 2. Brownouts on November 9 and November 16 (16:00-18:00 UTC) preview the change, and private and internal repositories are unaffected.

Why it matters: Public-repo workflows that depend on this trigger will break on December 2 unless allow-listed, and the change closes a well-known path for untrusted fork code to reach repository secrets.
