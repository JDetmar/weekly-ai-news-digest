Claude Code: idle-session compaction and unattended-run controls

Recent Claude Code releases (v2.1.299 to v2.1.302) compact a conversation of 200K+ tokens that has sat idle for about 54 minutes, before its one-hour prompt cache expires, and add a /config toggle for it. They also add CLAUDE_CODE_AUTO_MODE_MODEL to pick the auto-mode classifier model, a retry-watchdog cap on long usage-limit waits, and a switch that passes @-mentioned file paths instead of contents.

Why it matters: Idle compaction avoids reprocessing a huge context after a coffee break, and the new knobs make long unattended agent runs cheaper and more predictable.

MCP for agent-to-agent comms may be the riskiest protocol you've never heard of

Over five months, Google and four other organizations have acknowledged vulnerabilities in which one compromised agent passes malicious instructions to other internal agents that trust it. An independent researcher tested agents from Google, JP Morgan Chase, Weaviate, Rapid7, and French and US government bodies, and traced the problem to trust gaps in MCP.

Why it matters: If you chain agents over MCP, each agent's output has to be treated as untrusted input to the next, since guardrails inside individual agents are often lax or absent.
