Anthropic VS code extension on Cursor backdoored for nearly 12 hours

A malicious version 2.1.313 of Anthropic’s Claude extension was published through the official account on Cursor’s marketplace, reaching at most 5,000 users. It tried to install a persistent SSH backdoor and collected environment-variable names to inventory cloud credentials; Anthropic shipped 2.1.314 hours later, and how attackers got the account is still unexplained.

💡 Why it matters: Agentic coding extensions run with the IDE’s full permissions, so a hijacked publisher account is a direct path to source code and cloud credentials; check your installed version and rotate secrets if you ran 2.1.313.
