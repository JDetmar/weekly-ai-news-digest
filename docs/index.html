Anthropic VS Code extension on Cursor backdoored for nearly 12 hours

Version 2.1.313 of Anthropic’s Claude extension was published through Anthropic’s official Cursor account and stayed up until 2.1.314 replaced it several hours later; Cursor says at most 5,000 users were affected.
