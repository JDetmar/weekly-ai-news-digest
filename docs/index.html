AI Engineering
High
MCP for agent-to-agent comms may be the riskiest protocol you’ve never heard of

An independent researcher showed proof-of-concept attacks on agents from Google, JP Morgan Chase, Rapid7, and others that abuse trust gaps in MCP to pass malicious prompts from one internal agent to the next. Because agents trust each other and MCP servers hold credentials, exploits the LLM would refuse can succeed, often via server-side request forgery.

💡 Why it matters: Anyone wiring agents together over MCP needs per-agent guardrails and least-privilege credentials rather than assuming internal peers are trustworthy.
