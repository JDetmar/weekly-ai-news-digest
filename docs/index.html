Claude Code v2.1.305–v2.1.309: sandbox and permission hardening

Recent releases fix several sandbox gaps: shell startup files running outside the sandbox before each command on macOS and Linux, macOS denyWrite globs missed when a folder is reached through a symlink, and sandboxed commands being able to modify the MCP config passed with --mcp-config. v2.1.305 also added sandbox.allowNestedUserNamespaces for Chromium and rootless podman, which its notes say lets commands get around the sandbox’s file protections.

💡 Why it matters: Anyone running Claude Code unattended should upgrade promptly and think carefully before enabling the nested user namespace option.
